## 1. 志愿状态徽章渲染重构 (`Fit & Unfit Radar`)

找到 `currentScenario.covered_programs` 的渲染位置，根据 `p.fit_status` 区分展示：

### 1.1 状态枚举与视觉对应表

| `fit_status` | 徽章文案 | 背景与边框样式 | 适用场景 |
| :--- | :--- | :--- | :--- |
| `FULLY_COVERED` | ✅ 全达标 (纯英授课) | `bg-emerald-950 text-emerald-300 border-emerald-800` | 纯英文授课专业 |
| `SUBJECT_FIT_EXTERNAL_LANG_REQ` | ⚠️ 学科达标 · 需外考语言 | `bg-cyan-950/80 text-cyan-300 border-cyan-700` | 德语/荷兰语等授课，需单考德福/NT2 |
| `UNFIT` | ❌ 不兼容 | `bg-amber-950 text-amber-300 border-amber-800` | 缺失必修学科 |

### 1.2 Tailwind JSX 实现代码

```jsx
{/* 支持与兼顾志愿列表 */}
<div className="space-y-1.5">
  <div className="text-[11px] font-bold text-emerald-400 flex items-center justify-between">
    <div className="flex items-center gap-1">
      <CheckCircle2 className="w-3.5 h-3.5 text-emerald-400" />
      <span>本方案可兼顾申报的大学志愿 ({currentScenario.covered_programs.length})</span>
    </div>
    <span className="text-[10px] text-slate-400 font-normal">核验数理与授课语种</span>
  </div>

  <div className="grid grid-cols-1 gap-2">
    {currentScenario.covered_programs.map((p) => {
      const isExternalLang = p.fit_status === 'SUBJECT_FIT_EXTERNAL_LANG_REQ';

      return (
        <div 
          key={p.program_id} 
          className={`p-2.5 rounded-xl border text-xs space-y-1.5 transition ${
            isExternalLang 
              ? 'bg-slate-950/80 border-cyan-800/60' 
              : 'bg-emerald-950/20 border-emerald-900/40'
          }`}
        >
          <div className="flex items-center justify-between gap-2">
            <div className="flex items-center gap-1.5 min-w-0">
              <span className="shrink-0">{p.flag_emoji}</span>
              <span className="font-semibold text-white truncate">{p.university_name}</span>
              <span className="text-slate-400 text-[11px] truncate">- {p.program_name}</span>
            </div>

            {/* 精确状态标签 */}
            {isExternalLang ? (
              <span className="text-[10px] shrink-0 text-cyan-300 bg-cyan-950 px-2 py-0.5 rounded-md border border-cyan-700 font-bold flex items-center gap-1">
                <span>学科达标 · 需外考语言</span>
              </span>
            ) : (
              <span className="text-[10px] shrink-0 text-emerald-300 bg-emerald-950 px-2 py-0.5 rounded-md border border-emerald-800 font-medium">
                全达标 (纯英)
              </span>
            )}
          </div>

          {/* 针对外考语言的详细提示条 */}
          {isExternalLang && (
            <div className="text-[10px] text-cyan-200/90 bg-cyan-950/40 p-2 rounded-lg border border-cyan-900/50 leading-relaxed flex items-start gap-1.5">
              <span className="text-cyan-400 font-bold shrink-0">💡 语言提示:</span>
              <span>{p.language_tip || `大学为${p.instruction_language}授课，IB完成数理要求后，需在入学前单考提交 ${p.external_language_test_req}。`}</span>
            </div>
          )}
        </div>
      );
    })}
  </div>
</div>
```
