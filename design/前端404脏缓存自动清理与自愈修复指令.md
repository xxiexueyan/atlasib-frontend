# Copilot Task: 修复前端 LocalStorage 缓存过期导致的 UserProfile 404 弹窗报错

> **Role & Task:**
> 你是精通 React 与 Axios 的前端专家。
> 当用户浏览器本地残留了已不存在的 `atlasib_profile_id`（例如切换了后端数据库或重置了数据）时，
> 前端请求 `/profiles/{profile_id}` 或 `/profiles/{profile_id}/programs` 会收到 404 `UserProfile not found`。
> 
> **改造目标：**
> 1. 前端在捕获到 404 错误时，**绝不要弹出刺眼的错误提示**；
> 2. **自动就地自愈 (Self-Healing)**：清空本地失效的 `localStorage.removeItem('atlasib_profile_id')` 并将 `currentProfileId` 重置为 `null`；
> 3. 让系统平滑回退到“默认匿名访客状态”，保留默认的 2~3 个示例专业，允许用户重新做诊断或添加志愿生成新的合法 Profile。

---

## 步骤 1：重构 `src/context/PlanContext.jsx` 中的初始化数据拉取

请检查并替换 `src/context/PlanContext.jsx` 中读取已存志愿的 `useEffect`：

```javascript
// src/context/PlanContext.jsx

// 1. 初始化拉取逻辑改造：遇到 404 自动抹除本地失效脏 ID
useEffect(() => {
  if (currentProfileId) {
    userProgramApi.getSelectedPrograms(currentProfileId)
      .then(res => {
        if (res.data && res.data.length > 0) {
          setSelectedProgramIds(res.data.map(item => item.program_id));
        }
      })
      .catch(err => {
        // 如果后端返回 404，说明该 profile_id 在当前后端数据库中已不存在（如重置或切换了数据库）
        if (err.response && err.response.status === 404) {
          console.warn('[Self-Healing] Local profile ID expired or not found on server. Clearing stale cache.');
          localStorage.removeItem('atlasib_profile_id');
          localStorage.removeItem('atlasib_saved_email');
          setCurrentProfileId(null);
          // 保留系统默认推荐的示例志愿，不阻塞用户继续浏览
        } else {
          // 仅记录网络等其他异常，不向用户弹窗报错
          console.warn('Network issue fetching saved programs, using offline fallback', err);
        }
      });
  }
}, [currentProfileId]);
```

## 步骤 2：优化 Axios 全局拦截器 (`src/api/client.js`)

如果在其他视图（如进入向导或刷新）调用其他 profile 详情接口，避免全局 Toast 弹出 404 弹窗：

```javascript
// src/api/client.js 响应拦截器片段
client.interceptors.response.use(
  (response) => response,
  (error) => {
    // 若特定 profile 请求出现 404，静默抛出交由上层上下文清理，不触发全局红屏或刺眼 Alert
    if (error.response && error.response.status === 404 && error.config?.url?.includes('/profiles/')) {
      return Promise.reject(error);
    }
    // 其他严重错误再做常规提示
    return Promise.reject(error);
  }
);
```
