# AtlasIB 前端中英文双语适配开发指南 (默认 English，支持一键切中文)

> **致 AI 助手 (GitHub Copilot / Cursor):**
> 请严格根据本文档的规范与代码模板，在前端应用中实现 **English (默认)** 与 **简体中文 (zh)** 的平滑国际化切换。
> 页面上除专有名词外，所有静态 UI 文案、提示词、按钮以及动态接口字段均支持双语化展示。

---

## 1. 核心业务原则

1. **默认语言为 English (`en`)**：
   - 当用户首次进入、未在本地设置过语言时，系统强制以 **English** 作为主语言；
   - 用户切换语言后，选择存入 `localStorage`，后续访问保持用户选择。
2. **Axios 请求头严格联动**：
   - 所有向后端发送的 API 请求，必须在请求头中自动携带 `Accept-Language: en` 或 `Accept-Language: zh`，以便后端精准返回对应语种的大学/专业/排课结果。
3. **专业专有名词保留规范**：
   - 英文版与中文版中，`Math AA HL`, `Physics HL`, `CAS`, `EE`, `TOK`, `Co-op`, `PGWP` 等国际公认缩写统一保留大写规范，不进行过度直译。

## 2. 国际化初始化配置 (`src/i18n.js`)

在 `src/i18n.js` 中创建如下配置：

```javascript
import i18n from 'i18next';
import { initReactI18next } from 'react-i18next';
import LanguageDetector from 'i18next-browser-languagedetector';

// 导入中英文文案资源包
import enTranslation from './locales/en/translation.json';
import zhTranslation from './locales/zh/translation.json';

i18n
  .use(LanguageDetector)
  .use(initReactI18next)
  .init({
    resources: {
      en: { translation: enTranslation },
      zh: { translation: zhTranslation }
    },
    // 强制设定默认语言为英文
    fallbackLng: 'en',
    lng: localStorage.getItem('i18nextLng') || 'en',
    debug: false,
    interpolation: {
      escapeValue: false
    },
    detection: {
      order: ['localStorage', 'navigator'],
      lookupLocalStorage: 'i18nextLng',
      caches: ['localStorage']
    }
  });

// 如果 localStorage 暂无记录，显式初始化为 'en'
if (!localStorage.getItem('i18nextLng')) {
  localStorage.setItem('i18nextLng', 'en');
}

export default i18n;
```

并在 `src/main.jsx` 最顶部导入：
```javascript
import React from 'react';
import ReactDOM from 'react-dom/client';
import App from './App.jsx';
import './index.css';
import './i18n'; // 确保在 App 渲染前初始化
```

## 4. Axios 拦截器注入 `Accept-Language` (`src/api/client.js`)

确保客户端向后端发送的每个请求都携带当前激活语言代码：

```javascript
import axios from 'axios';
import i18n from '../i18n';

const client = axios.create({
  baseURL: import.meta.env.VITE_API_BASE_URL || 'http://127.0.0.1:8000/api/v1',
  timeout: 10000
});

client.interceptors.request.use((config) => {
  // 提取当前语言：若以 'zh' 开头则为 'zh'，其余所有情况严格默认为 'en'
  const currentLang = (i18n.language && i18n.language.startsWith('zh')) ? 'zh' : 'en';
  config.headers['Accept-Language'] = currentLang;
  return config;
});

export default client;
```

## 5. 顶部语言切换按钮组件接入 (`src/components/common/Header.jsx` 或 `App.jsx`)

在顶部导航右侧放置语言切换器（显示当前语言并在点击时瞬间切换）：

```jsx
import React from 'react';
import { useTranslation } from 'react-i18next';
import { Globe } from 'lucide-react';

export default function LanguageSwitch() {
  const { i18n } = useTranslation();
  const isEn = !i18n.language || i18n.language.startsWith('en');

  const toggleLanguage = () => {
    const nextLang = isEn ? 'zh' : 'en';
    i18n.changeLanguage(nextLang);
    localStorage.setItem('i18nextLng', nextLang);
  };

  return (
    <button
      onClick={toggleLanguage}
      className="px-2 py-1 rounded-lg bg-slate-900 border border-slate-700/80 text-[11px] text-slate-200 hover:text-white flex items-center gap-1 transition"
      title="Switch Language / 切换语言"
    >
      <Globe className="w-3.5 h-3.5 text-cyan-400" />
      <span className="font-semibold">{isEn ? '中文' : 'EN'}</span>
    </button>
  );
}
```

## 6. 视图替换指引

请扫描所有 JSX 文件（如 `App.jsx`、`HarmonizerView.jsx`、`ProgramsView.jsx`），将静态中文硬编码替换为 `t('key')` 调用：
1. 导入钩子：`import { useTranslation } from 'react-i18next';`
2. 初始化：`const { t } = useTranslation();`
3. 替换文案：
   - 底部 Tab：`{t('nav.wizard')}`, `{t('nav.programs')}`, `{t('nav.harmonizer')}`
   - 按钮：`{t('common.add_to_cart')}`, `{t('common.in_cart')}`
   - 状态徽章：
     - 若 `fit_status === 'FULLY_COVERED'` 则展示 `{t('status_badges.fully_covered')}`
     - 若 `fit_status === 'SUBJECT_FIT_EXTERNAL_LANG_REQ'` 则展示 `{t('status_badges.subject_fit_lang_req')}`
