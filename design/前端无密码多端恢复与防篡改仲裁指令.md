# Copilot Task: 前端无密码跨端免密恢复、Magic Token 鉴权与防覆盖弹窗落地

> **Role & Task:**
> 你是精通 React + Tailwind CSS + react-i18next 的资深前端工程师。
> 请改造前端架构，实现真正的**无密码多端识别与安全数据恢复**：
> 1. **URL 参数自愈拦截 (`restore_token`)**：
>    当用户在不同设备（手机或新电脑）点击邮件中的按钮时，前端检测到 URL 包含 `?restore_token=xxx`，自动调用后端 `/api/v1/auth/restore-session` 完成全套方案、已选志愿与 Profile 的无感恢复，并清理地址栏参数；
> 2. **防覆盖/防篡改仲裁弹窗 (`RestoreConflictModal.jsx`)**：
>    若后端提示 `is_conflict_candidate: true`（表示当前设备产生的新方案与该邮箱历史保存的档案发生碰撞），弹窗引导真实用户选择：
>    - **【覆盖历史旧档案】**：将当前新方案作为该邮箱的主方案；
>    - **【保留为独立备选方案】**：不覆盖旧数据，安全共存；
> 3. **API 与 Context 联动**：
>    在 `src/api/userPrograms.js` 中扩充对应认证接口，并在 `PlanContext.jsx` 中统一接管跨端恢复流程。

## 步骤 2：更新前端 API 客户端 (`src/api/userPrograms.js`)

追加两端点封装：

```javascript
// src/api/userPrograms.js
import client from './client';

export const userProgramApi = {
  // ... 保留已有接口 ...

  // 凭邮件中的 restore_token 找回历史会话
  restoreSessionByToken: (token) =>
    client.get(`/auth/restore-session?token=${encodeURIComponent(token)}`),

  // 老用户确认合并或覆盖
  resolveConflict: (restoreToken, action) =>
    client.post('/auth/resolve-claim-conflict', {
      restore_token: restoreToken,
      action: action // 'OVERWRITE' | 'KEEP_NEW'
    })
};
```

## 步骤 3：编写防串号仲裁弹窗组件 (`src/components/common/RestoreConflictModal.jsx`)

新建 `src/components/common/RestoreConflictModal.jsx`：

```jsx
import React, { useState } from 'react';
import { useTranslation } from 'react-i18next';
import { AlertCircle, RefreshCw, CheckCircle2, ShieldCheck, Loader2 } from 'lucide-react';
import { userProgramApi } from '../../api/userPrograms';

export default function RestoreConflictModal({ email, restoreToken, onResolved, onDismiss }) {
  const { t } = useTranslation();
  const [isSubmitting, setIsSubmitting] = useState(false);

  const handleAction = async (actionType) => {
    setIsSubmitting(true);
    try {
      await userProgramApi.resolveConflict(restoreToken, actionType);
      if (onResolved) onResolved(actionType);
    } catch (err) {
      console.error('Failed to resolve conflict', err);
    } finally {
      setIsSubmitting(false);
    }
  };

  return (
    <div className="fixed inset-0 z-50 bg-black/80 backdrop-blur-sm flex items-end sm:items-center justify-center p-3 animate-fadeIn">
      <div className="bg-slate-900 border border-indigo-700/80 w-full max-w-sm rounded-3xl p-5 space-y-3.5 shadow-2xl">
        <div className="flex items-center gap-2">
          <div className="w-8 h-8 rounded-full bg-amber-950/80 border border-amber-600/80 flex items-center justify-center shrink-0">
            <AlertCircle className="w-4 h-4 text-amber-400" />
          </div>
          <div>
            <h3 className="text-xs font-bold text-white">
              {t('restore_dialog.conflict_title')}
            </h3>
            <span className="text-[10px] text-cyan-400 font-mono">{email}</span>
          </div>
        </div>

        <p className="text-[11px] text-slate-300 leading-relaxed">
          {t('restore_dialog.conflict_desc', { email })}
        </p>

        <div className="pt-2 space-y-2">
          <button
            type="button"
            disabled={isSubmitting}
            onClick={() => handleAction('OVERWRITE')}
            className="w-full py-2.5 px-3 bg-gradient-to-r from-indigo-600 to-cyan-600 hover:opacity-95 text-white font-bold text-xs rounded-xl flex items-center justify-center gap-1.5 transition disabled:opacity-50"
          >
            {isSubmitting ? (
              <Loader2 className="w-3.5 h-3.5 animate-spin" />
            ) : (
              <>
                <RefreshCw className="w-3.5 h-3.5" />
                <span>{t('restore_dialog.btn_overwrite')}</span>
              </>
            )}
          </button>

          <button
            type="button"
            disabled={isSubmitting}
            onClick={() => handleAction('KEEP_NEW')}
            className="w-full py-2 px-3 bg-slate-950 hover:bg-slate-800 text-slate-300 font-semibold text-xs rounded-xl border border-slate-700 transition"
          >
            {t('restore_dialog.btn_keep_both')}
          </button>
        </div>

        <div className="pt-1 flex items-center justify-center gap-1 text-[10px] text-slate-500">
          <ShieldCheck className="w-3 h-3 text-emerald-400" />
          <span>Protected by Magic Link Identity Verification</span>
        </div>
      </div>
    </div>
  );
}
```

## 步骤 4：在 Context 全局监听并自动恢复 (`src/context/PlanContext.jsx`)

在 `src/context/PlanContext.jsx` 中增加对 URL Query 参数 `restore_token` 的自动扫描与会话恢复：

```jsx
// src/context/PlanContext.jsx
import React, { createContext, useContext, useState, useEffect } from 'react';
import { userProgramApi } from '../api/userPrograms';

const PlanContext = createContext(null);

export const PlanProvider = ({ children }) => {
  const [currentProfileId, setCurrentProfileId] = useState(() => localStorage.getItem('atlasib_profile_id') || null);
  const [selectedProgramIds, setSelectedProgramIds] = useState(['waterloo_se', 'oxford_cs']);
  const [conflictCandidate, setConflictCandidate] = useState(null); // { email, restoreToken }

  // 跨端 URL Token 自动扫描与免密接管
  useEffect(() => {
    const params = new URLSearchParams(window.location.search);
    const token = params.get('restore_token');

    if (token) {
      userProgramApi.restoreSessionByToken(token)
        .then((res) => {
          const data = res.data;
          if (data && data.success) {
            // 1. 同步恢复本地 Profile ID 与志愿
            setCurrentProfileId(data.profile_id);
            localStorage.setItem('atlasib_profile_id', data.profile_id);
            localStorage.setItem('atlasib_saved_email', data.email);

            if (data.selected_program_ids && data.selected_program_ids.length > 0) {
              setSelectedProgramIds(data.selected_program_ids);
            }

            // 2. 若存在冲突候选，触发弹窗确认
            if (data.is_conflict_candidate) {
              setConflictCandidate({
                email: data.email,
                restoreToken: token
              });
            }

            // 3. 干净清除地址栏中的 query 参数
            window.history.replaceState({}, document.title, window.location.pathname);
          }
        })
        .catch((err) => {
          console.warn('[Restore] Invalid or expired restore link', err);
        });
    }
  }, []);

  return (
    <PlanContext.Provider value={{
      currentProfileId,
      setCurrentProfileId,
      selectedProgramIds,
      setSelectedProgramIds,
      conflictCandidate,
      setConflictCandidate
    }}>
      {children}
    </PlanContext.Provider>
  );
};

export const usePlan = () => useContext(PlanContext);
```
